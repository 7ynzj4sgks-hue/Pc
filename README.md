# NEXUS — Gaming Command Center

## Run locally
Open `index.html` in a browser. For best results, use a local development server.

## Publish with GitHub Pages
1. Create a GitHub repository named `nexus-gaming-command-center`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.

## Features
- Dashboard and responsive navigation
- Searchable/filterable game library with detail modals
- Simulated FPS chart and sample CPU/GPU load
- Sample gaming news summaries
- Editable PC setup cards
- Theme, glow, compact-card and reduced-motion settings
- Local theme preference storage

Note: Performance figures are demo values. This static website does not read actual PC hardware or game FPS.
